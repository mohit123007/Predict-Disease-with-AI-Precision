## 🚀 Quick Start

### 1. Create a Virtual Environment

```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. (Optional) Train the Example ML Model

```bash
python scripts/train_example_model.py
```

### 4. Start the Server

```bash
uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000
```

### 5. Open in Browser

```
http://localhost:8000
```

## 🔌 API Endpoints

### Authentication
| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/auth/register` | Create new user account |
| POST | `/auth/login` | Login → returns JWT token |

### Disease Prediction
| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/predict/tabular` | Predict disease from structured features |
| POST | `/predict/image` | Predict disease from medical image |
| GET  | `/predict/history` | Get user's prediction history |

### AI Features
| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/ai/chatbot` | Medical Q&A chatbot |
| POST | `/ai/symptoms` | Symptom checker |
| POST | `/ai/health-score` | Compute health score + recommendations |
| POST | `/ai/doctor-recommend` | Suggest specialists |
| POST | `/ai/risk` | Risk score calculator |
| POST | `/ai/upload-report` | Analyze medical report text |
| POST | `/ai/explain` | Get explainable AI feature contributions |
| GET  | `/ai/history` | User's AI feature usage history |

```python
class Settings:

    ACCESS_TOKEN_EXPIRE_MINUTES = 60
    ALGORITHM = "HS256"
```

---

## 🔒 Security Notes

- Change `SECRET_KEY` in `config.py` before any production deployment
- All API endpoints (except `/auth/register` and `/auth/login`) require a valid JWT Bearer token
- Passwords are hashed using bcrypt via passlib
- For production: use HTTPS, restrict CORS origins, and review PHI handling regulations

---

## 📦 Adding a Real ML Model

1. Place your trained model file at `models/xgboost/model.joblib`
2. The model must implement `predict_proba(X)` returning `[negative_prob, positive_prob]`
3. Or run the training script: `python scripts/train_example_model.py`
4. For image models: update `ai_modules/medical_image_prediction.py` with your CNN inference code
